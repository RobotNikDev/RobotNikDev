## 🚀 Проекты в разработке (My Roadmap)

### 1. Автономный робот-балансир (на базе Yahboom)
* **Суть:** Изучение ROS2, навигации и распределенных вычислений.
* **Технологии:** Raspberry Pi + AI hat ⇄ Linux PC (распределение тяжелых вычислений), лидар, камера Orbbec Astra Pro.
* **Задачи:** Реализация SLAM, автономная навигация, распознавание объектов на борту.

### 2. Настольный 6-осевой манипулятор
* **Суть:** Управление многоосевой кинематикой и пространственное зрение.
* **Технологии:** Xiao ESP32 S3 Sense, RP2040, драйвер PCA9685, 6 сервоприводов MG996R, 3D ToF-матрица (VL53LCX).

### 3. Автономный робот-гексапод
* **Суть:** Разработка шагающего робота со сложной биомиметической кинематикой (18 сервоприводов).
* **Технологии:** Плата Waveshare (ESP32), Raspberry Pi + AI hat, Astra Pro, лидар, сервоприводы ST3215.

### 4. Робосистема: Коллаборация роботов (Multi-Agent System)
* **Суть:** Организация взаимодействия робота-балансира, манипулятора и гексапода.
* **Сценарий:** Манипулятор загружает гексапод ➔ гексапод находит человека в комнате по камере ➔ доставляет предмет и следует за ним.
